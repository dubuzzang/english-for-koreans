# Hello — 한국인을 위한 영어

한국어 화자에게 맞춘 영어 학습 웹앱입니다. 휴대폰 브라우저에 최적화되어 있고, 설치 없이 바로 쓸 수 있어요.
[Merhaba(한국인을 위한 튀르키예어)](https://turkish-for-koreans.pages.dev/)와 같은 구조로 만든 영어판이에요.

**바로 사용하기 → https://english-for-koreans.pages.dev/**

| 설치 | 방법 |
|---|---|
| 안드로이드 | [Hello 앱 내려받기 (APK)](https://english-for-koreans.pages.dev/download/hello.apk) → 열어서 설치 (구글 플레이 밖 앱이라 "출처를 알 수 없는 앱" 허용 필요) |

## 왜 한국인에게 맞춤인가

단어는 아는데 말이 안 나오는 이유는 대부분 **문장을 만드는 방식**이 달라서예요. 이 앱은 그 차이를 한국어와 견주어 짚어 줍니다.

| 영어 | 한국어 | 이 앱에서 |
|---|---|---|
| 주어-동사-목적어 | 주어-목적어-동사 | 어순 노트, 문장 조립 타일 |
| 관사 a / an / the | 없음 | a/an은 **소리**로 정한다 (an hour, a university) — 드릴 |
| 3인칭 단수 -s, do/does | 동사가 주어와 상관없음 | 동사 시제 드릴의 오답이 실제 실수로 만들어짐 (doesn't plays) |
| 셀 수 없는 명사 | 구분 없음 | bread·rice·advice — 단어장에 표시, 복수 드릴 |
| 전치사 in/on/at | 조사 '에' 하나 | 시간·장소 전치사 드릴 |
| f·v·th·r·l·z | 한국어에 없는 소리 | 최소대립쌍 듣기 퀴즈 (fan/pan, right/light, think/sink) |
| 콩글리시 | 핸드폰·아파트·원피스·헬스장 | 단어 메모로 바로잡기 (phone·apartment·dress·gym) |

## 학습 효과를 위한 설계

- **인출 연습 중심 레슨**: 짧게 보여 주고 곧바로 떠올리게 합니다(객관식 → 짝 맞추기 → 문법 확인 → 문장 조립 → 직접 쓰기 → 말하기).
- **오답 재출제**: 틀린 문제는 레슨 끝에 다시 나오고, 틀린 단어는 복습 카드에서 더 일찍 돌아옵니다.
- **간격 반복(FSRS-5)**: 기억률 90%를 유지하도록 다음 복습일을 계산합니다. 인식(영어→뜻)이 익숙해지면 산출(뜻→영어) 카드가 열립니다.
- **한글 발음 표기 + 강세(선택)**: CMU 발음 사전으로 미국식 발음을 한글로 옮기고 강세 음절을 굵게 — water [워러], computer [컴**퓨**러]. 익숙해지면 끌 수 있습니다.
- **약점 공략**: 자주 틀린 단어·문장·문법만 모아 다시 연습합니다.
- **매일 습관**: 하루 목표 XP, 연속 학습일, 오늘의 표현.

## 구성

- **0단원 발음 기초** — 알파벳 26자(한국인 주의 글자 표시), 헷갈리는 소리 10종 최소대립쌍, 강세·약모음·연음·미국식 t
- **학습 경로 15단원·레슨 60개** — 첫 만남 · 나와 가족 · 있다/없다 · 숫자와 쇼핑 · 식당·카페 · 나의 하루 · 지금 하는 일 · 시간과 날짜 · 이동과 여행 · 과거 · 미래와 계획 · 능력과 의무 · 몸과 건강 · 비교와 묘사 · 경험과 문장 잇기
- **문법 노트 34개** — 한국어와 비교한 설명, 예문 듣기, 표
- **문법 드릴 7종(무한 생성)** — be동사, 동사 시제(12가지 × 인칭 × 부정·질문), 불규칙 동사, a/an·복수, 비교급·최상급, 인칭대명사, 전치사 · 정답을 색깔별로 풀이
- **숫자·시각 드릴** — 듣고 숫자 쓰기(13/30 구분), 달러 가격, 시계 보고 말하기(숫자대로 · past/to)
- **상황별 회화 16개** — 입국 심사·택시·호텔·길 묻기·식당·카페·옷 가게·약국·지하철·공항 체크인·병원 등, 전체 듣기·번역 가리기·역할 연습
- **생존 표현집** — 긴급·식당·쇼핑·교통·숙소·건강·공항 등 107문장
- **말하기 연습** — 음성 인식으로 발음 확인(크롬·사파리)
- **복습** — FSRS 플래시카드, 주제별 새 단어 늘리기
- **연습** — 단어 퀴즈, 듣기 훈련, 문장 조립, 쓰기, 받아쓰기, 발음 구분, 약점 공략
- **단어장** — 예문·메모가 있는 핵심 단어 1,001개, 검색과 주제별 보기, 복수형·비교급·동사 활용표
- **학습 통계** — 30일 XP, 12주 히트맵, 7일 복습 예보, 단원별 진행
- **오프라인·앱 설치(PWA)** — 홈 화면에 설치하면 인터넷 없이도 학습
- **원어민 AI 발음** — 단어·예문·회화 등 약 5,300개 문장을 미국 영어 AI 음성으로 미리 녹음(회화는 남녀 목소리), 음성 인식기로 받아써서 검사를 통과한 것만 사용

## 사용 팁

- 발음은 미리 녹음한 음성 파일로 재생돼서 기기와 상관없이 같은 소리가 나요. 문법 드릴이 그때그때 만드는 문장은 기기의 영어 음성으로 읽어요.
- 학습 기록은 브라우저(localStorage)에만 저장됩니다. 기기를 바꿀 때는 **설정 → 백업 내보내기/불러오기**를 쓰세요.

## 개발

빌드 도구 없이 순수 HTML·CSS·JavaScript(ES 모듈)로 만들었습니다.

```bash
npm test          # 핵심 로직·데이터 테스트 (Node 20+)
npm run serve     # http://localhost:5174 (Python 필요, 오프라인 테스트는 ?sw=1)
npm run pron      # 데이터를 고친 뒤: 발음 사전(js/data/pron.js) 다시 만들기
npm run build:sw  # 파일을 추가·삭제했거나 버전을 올린 뒤 sw.js 다시 만들기
node scripts/audio.mjs texts   # 데이터를 고친 뒤: 녹음할 문장 목록
node scripts/audio.mjs index   # 음성 파일을 만든 뒤: audio/index.json 갱신
```

```
index.html, css/app.css
js/app.js               라우터·앱 셸
js/core/                채점(en), 형태 엔진(morph), 문법 드릴(drillgen), 한글 표기(hangul·pron), 숫자(numbers), FSRS(srs), 덱(deck), 저장(store), 음성(tts·audiokey·stt), UI
js/data/                단어(vocab-*.js), 커리큘럼, 문법 노트, 알파벳·발음, 회화, 표현집, 오늘의 표현, 발음 사전(pron.js, 자동 생성)
js/views/               화면(홈·학습·레슨·복습·연습·단어장·발음·회화·설정)
audio/                  녹음 음성(mp3)과 목록(index.json)
tools/tts/              녹음 음성 생성·검사 도구(Python) — tools/tts/README.md
tools/pron/             CMU 발음 사전(내려받기)
tests/                  node:test 테스트
```

녹음 음성은 [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)(Apache-2.0)로 만들었고, 한글 발음 표기는 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)(BSD)를 씁니다.

Cloudflare Pages는 `npm run deploy:cf`(wrangler 로그인 필요)로 배포합니다. 버전별 변경 사항은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
